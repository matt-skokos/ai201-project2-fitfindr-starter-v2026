## Tool Inventory

### `search_listings`

- **What it does:**
- **Inputs:** 
     1. description (string) which should describe in words what the user wants
     2. size (string) which should be case insensitive and have different forms for hoodies/shirts, shoes and bottoms. 
     3. max_price (string) which should be parsed to a a float to match the data.
- **Returns:**
Returns a **list of dictionaries** which are pulled from the listings.json and will return the objects as a dictionary carrying all of the data in a listing: id, title, description, category, etc. 
- **When it has nothing:**
If nothing is found with search, its returns an **empty list**.

### `suggest_outfit`

- **What it does:** This is one of the two methods that uses generate to call the model.
It will take in the user's wardrobe and a thrifted item to decide on what to return as an
outfit suggestion to the user. It will use comparisons between the suggested target item
and what's in their wardrobe to do this.
- **Inputs:**
1. new_item (listing dict()) that contains data for the user's target item. 
2. wardrobe (dict() containing users wardrobe list) this matches with the thrift items in 
features and can be compared / contrasted as such. Also much deal with an empty wardrobe.
Some ideas are to suggest a 2nd or 3rd thrifted item ?
- **Returns:**
Will return a non-empty string with suggestions for the user. Again this will be generated
by the model and built from the search prompt. You must handle empty results caused by 
nothing in the wardrobe so as above, try to suggest a full outfit from the options above.
- **When it has nothing:**
You must handle empty results caused by nothing in the wardrobe so as above, try to suggest a full outfit from the options above.
### `create_fit_card`

- **What it does:** This will create a short caption that would serve as a kind of social media post about the purchase/find. Like "suggest" it will be generated by the model as well.
- **Inputs:** 
1. outfit (string) this will be passed to the function by suggest_outfit() above. It will contain the non-empty string that describes the outfit from the search prompt.
2. new_item (listing dict()) will take in the target item for the user. It will have all relevant data that each listing has: category, title, id, description, etc.
- **Returns:**
A 2-4 sentence description of the outfit. This will use the inputs and provide a human-readable formatted description of the current outfit.
- **When it has nothing:**
When nothing comes back, revert to the strategy above: make some suggestions from the thrifting list for a full outfit for the user. This will fit in nicely with suggest_outfit's return as it can build the reply with it.

To keep it simple I'll use regex parsing: return a JSON object {description: string, max_price: float, size: string }

The query is passed in to the loop along with a persons empty or non-empty user wardrrobe at initialization of the session.
